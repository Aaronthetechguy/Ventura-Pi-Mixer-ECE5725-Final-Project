JACK_guide.txt

Description:
This file is a quick setup and troubleshooting guide for running the live EQ
project with JACK on a Raspberry Pi or Linux audio system.

1. Check the device name/number
arecord -l
aplay -l

ex: card 1: CODEC [USB Audio CODEC], device 0: USB Audio [USB Audio]
would be hw:1

-----------------------------------------------------------------------------

2. Start JACK on the UMC22

First try:

jackd -R -P70 -dalsa -dhw:1 -r48000 -p64 -n2

If that fails, try:

jackd -R -P70 -dalsa -dhw:1 -r48000 -p128 -n2

-----------------------------------------------------------------------------

3. See JACK ports

Open another terminal:

jack_lsp

You should see ports like:

system:capture_1
system:capture_2
system:playback_1
system:playback_2

-----------------------------------------------------------------------------

4. Route input to output

For left input to left output:

jack_connect system:capture_1 system:playback_1

If your signal is actually on channel 2, use:

jack_connect system:capture_2 system:playback_1

-----------------------------------------------------------------------------

5. Remove unwanted connections
jack_disconnect system:capture_1 system:playback_2
jack_disconnect system:capture_2 system:playback_1
jack_disconnect system:capture_2 system:playback_2

-----------------------------------------------------------------------------

6. Verify connections
jack_lsp -c

You want to see something like:

system:capture_1
   system:playback_1

-----------------------------------------------------------------------------
7. Hardware checks

plug headphones/speaker into the UMC22 output
mic/instrument into the UMC22 input
turn up GAIN
turn up OUTPUT
turn DIRECT MONITOR OFF if you only want to hear JACK-routed audio

-----------------------------------------------------------------------------

8. If no sound

Test both input channels:

jack_connect system:capture_1 system:playback_1
jack_connect system:capture_2 system:playback_1





=================================================
Open a terminal in the folder with your files.
Compile the C engine:
gcc audio_engine_rt2.c -o audio_engine_rt2 -O3 -march=native -Wall -Wextra -ljack -lpthread -lm

Start JACK first:
jackd -R -P70 -dalsa -dhw:YOUR_DEVICE -r48000 -p128 -n2
In a second terminal, run the Python GUI:
python3 main5_live.py
In a third terminal, list JACK ports:
jack_lsp
Connect your 2 mono USB inputs to the engine:
jack_connect system:capture_1 usb_eq_mixer:in1
jack_connect system:capture_2 usb_eq_mixer:in2
Connect the engine output to playback:
jack_connect usb_eq_mixer:outL system:playback_1
jack_connect usb_eq_mixer:outR system:playback_2
Test audio and move EQ in the GUI.
Once stable at -p128, try lower latency:
jackd -R -d alsa -d hw:YOUR_DEVICE -r 48000 -p 64 -n 2

Replace YOUR_DEVICE with your actual JACK/ALSA device name._
